# agentforce-healthcare-Force
MediCare Enrollment Assistant

Project Description

An AI-powered healthcare patient enrollment assistant built using Salesforce Agentforce.

The assistant helps patients:

- Check eligibility for health programs.
- Book medical appointments.
- Check enrollment application status.
- Understand required documents.
- Get assistance from human staff when needed.
